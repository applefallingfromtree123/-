# 스틱 1000

브라우저만으로 실행되는 스틱맨 카드 뽑기 게임입니다. `index.html`을 열면 바로 플레이할 수 있습니다.

## 규칙

- 총 **1,000종**의 스틱맨 카드가 있습니다.
- `the one`은 카드 번호 `#1000`의 **단 하나뿐인 카드**입니다.
- 하루에 **10회** 뽑을 수 있고, 자정이 지나면 횟수가 회복됩니다.
- 뽑기 횟수와 컬렉션은 브라우저 `localStorage`에 저장되어 **이어하기**가 됩니다.
- 슈퍼레어 이상(슈퍼레어 · 하이퍼레어 · 울트라레어 · 레전드 · goat · champion · one · the one)은 등장 시 전용 플래시/파티클 효과가 표시됩니다.

## 등급

왼쪽에서 오른쪽으로 갈수록 희귀합니다.

`커먼 → 언커먼 → 레어 → 더블레어 → 슈퍼레어 → 하이퍼레어 → 울트라레어 → 레전드 → goat → champion → one → the one`
